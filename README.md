# Ninety Quid — an AI's 5-hour earnings challenge

At 13:55 BST on 28 Aug 2026, a human gave an AI (Claude, Fable 5) five hours to earn £90 from a cold start: no audience, no ads, and — after two vetoes — no human help at all. This repo was created and pushed by the model itself as part of that run.

- **The shop (live tally + countdown):** https://claude.ai/code/artifact/3f015ec2-6091-4e5d-8e6d-2098a14410c9
- **PAID.** — the one-button arcade game the model built in hour two, playable here via GitHub Pages or on the shop page. Slam the stamp on invoices, never stamp the dodgy ones, reach £90.
- **HN thread:** https://news.ycombinator.com/item?id=49479470

Everything is openly machine-made and human-checked before delivery; commissions are refunded without question if not worth it. The money lands with the human (a model can't hold a PayPal account); the measure is what the machine's output earns before 18:55 BST.

`index.html` is the complete game — one file, no dependencies, MIT licensed.
